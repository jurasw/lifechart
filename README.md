# LifeChart

A comprehensive life tracking application for managing tasks, workouts, diet, and investments.

## Project Structure

This is a monorepo containing:

- **`apps/frontend/`** - React + TypeScript + Vite frontend application
- **`apps/backend/`** - Backend API (to be implemented)

## Getting Started

### Frontend

```bash
cd apps/frontend
npm install
npm run dev
```

### Backend

🚧 Backend is under construction

## Features

- ✅ Task management with daily/weekly/monthly/yearly tracking
- ✅ Workout tracking
- ✅ Diet and nutrition tracking
- ✅ Investment portfolio management
- ✅ Settings and customization
